Privasi

Kebijakan Privasi

Ringkasan ini menjelaskan bagaimana WorkSim memperlakukan data demo yang digunakan di dalam pengalaman website.

Data yang Disimpan

WorkSim dapat menyimpan data akun demo seperti nama, email, avatar, dan status sesi di browser pengguna melalui localStorage untuk menjalankan fitur simulasi login.

Penggunaan Data

Data demo digunakan untuk menampilkan pengalaman personal seperti navbar, akses halaman, dan profil skill. Data ini tidak dimaksudkan sebagai sistem autentikasi produksi.

Penyimpanan Lokal

Data yang tersimpan di browser dapat dihapus melalui fitur logout atau pengaturan penyimpanan browser. Hindari memakai informasi sensitif pada akun demo.

Kontak dan Pembaruan

Kebijakan ini dapat diperbarui saat fitur WorkSim berkembang. Pembaruan akan ditampilkan pada halaman ini.
